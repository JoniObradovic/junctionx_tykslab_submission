# Brand assets

`logo.png` is the Tyks logo and `region.png` the Varha logo, both taken from the public brand
material bank linked from tyks.fi and varha.fi (varha.kuvat.fi, "Logot ja graafinen ohjeisto").
The page shows `logo.png` in the brand block (also used as the tab icon) and `region.png` at the foot of the
sidebar; when a file is missing the drawn mark is used and the region slot stays empty.
